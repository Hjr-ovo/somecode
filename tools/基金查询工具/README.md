# 基金查询工具集（Fund Query Tools）

一个基于**东方财富公开接口**的基金数据查询小工具集，使用 Python 标准库实现，**无任何第三方依赖**。

> ⚠️ 仅供学习研究使用。数据来自东方财富公开网页接口，接口可能随时变更；查询结果不构成任何投资建议。

## 功能特性

- 🔍 **基金搜索**：按名称关键词或 6 位代码搜索基金，获取最新净值、类型、基金公司、基金经理等基础信息
- 📊 **基金综合分析**：输入基金代码，一键输出结构化分析报告（净值走势、阶段涨幅、规模、经理、资产配置、持有人结构、费率、业绩基准）
- 💰 **持仓收益报告**：批量查询持仓基金净值，计算市值、收益与收益率
- 📦 **零依赖**：仅用 Python 标准库（`urllib` / `json` / `re`），`pip install` 都不需要

## 环境要求

- Python 3.7+
- 可访问东方财富（eastmoney.com）网络接口

## 快速开始

```bash
# 1. 搜索基金（名称或代码）
python search_fund.py 摩根瑞享
python search_fund.py 016211

# 2. 基金综合分析（6位代码，可指定展示的交易日数）
python fund_profiler.py 016211
python fund_profiler.py 016211 --days 20

# 3. 持仓收益报告（默认内置示例持仓，或读取 holdings.json）
python holdings_report.py
python holdings_report.py --config my_holdings.json
```

## 持仓配置说明（holdings.json）

`holdings_report.py` 支持通过 JSON 配置文件指定你的持仓，便于随时复查收益。仓库内置的 `holdings.json` 仅为格式示例（脱敏数据），**请勿将个人真实持仓随代码上传**。

```json
{
  "110022": {
    "name": "易方达消费行业股票",
    "cost": 1000,
    "buy_nav": 3.5
  },
  "003358": {
    "name": "易方达中债7-10年国开行债券A",
    "cost": 1000,
    "buy_nav": 1.1
  }
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | 是 | 基金名称（仅用于展示） |
| `cost` | 是 | 买入金额（元） |
| `buy_nav` | 否 | 买入时的确认净值；填了才能计算收益/收益率，不填则按成本计入市值 |

保存为 `holdings.json` 放到本目录，或通过 `--config` 指定任意路径。
不配置时使用内置的示例持仓（脱敏的通用示例基金）。


## 核心模块 API

`eastmoney_api.py` 也可以作为库被其他脚本复用：

```python
from eastmoney_api import search_fund, get_fund_data, extract_js_var

# 搜索基金
items = search_fund("016211")
print(items[0]["SHORTNAME"], items[0]["DWJZ"])

# 获取基金核心数据（JS 文本）
js = get_fund_data("016211")

# 提取某个变量
nav_trend = extract_js_var(js, "Data_netWorthTrend")
# 返回的是 JS 数组文本，可再用 json.loads 解析
```

`get_fund_data()` 返回的 JS 文本中常用变量：

| 变量 | 含义 |
|------|------|
| `Data_netWorthTrend` | 单位净值走势 |
| `Data_ACWorthTrend` | 累计净值走势 |
| `Data_fluctuationScale` | 规模变动 |
| `Data_currentFundManager` | 现任基金经理 |
| `Data_assetAllocation` | 资产配置（股票/债券/现金占比） |
| `Data_holderStructure` | 持有人结构（机构/个人占比） |
| `syl_1y / syl_3y / syl_6y / syl_1n` | 近1月/近3月/近6月/近1年涨幅 |
| `fund_sourceRate` | 原费率 |
