### 1. filter（8.1.2_filter.py）

**练习题：**
- 利用 `filter()` 筛选出 1~1000 以内的所有回文数（如 12321、909）

**知识点：**
- `filter(f, list)`：把函数 `f` 依次作用于每个元素，根据返回值 `True/False` 决定保留或丢弃
- `filter` 返回惰性迭代器（Iterator），需用 `list()` 转成列表
- 与 `map()` 的区别：`map` 做变换（元素个数不变），`filter` 做筛选（元素个数可能减少）

**代码片段：**
```python
def is_palindrome(n):
    s = str(n)
    return s == s[::-1]

output = filter(is_palindrome, range(1, 1000))
print('1~1000:', list(output))
```

- 测试用例全部通过 ✅

### 2. sorted（8.1.3sorted.py）

**练习题：**
- 用 `sorted()` 对 `[('Bob', 75), ('Adam', 92), ('Bart', 66), ('Lisa', 88)]` 按名字排序
- 再按成绩从高到低排序

**知识点：**
- `sorted(list, key=func)`：`key` 指定排序依据的函数，作用于每个元素
- 按名字排序用 `key=by_name`（取 `t[0]`），按成绩排序用 `key=by_score`（取 `t[1]`）
- `sorted` 返回新列表，不改变原列表

**代码片段：**
```python
def by_name(t):
    return t[0]

L2 = sorted(L, key=by_name)
print(L2)  # 按名字排序

def by_score(t):
    return t[1]

L2 = sorted(L, key=by_score)
print(L2)  # 按成绩排序
```
