# Somecode

个人项目合集：能用的工具 + 学习归档。

顶部只保留 `tools/`（成品 / 在研工具）与 `archive/`（学习归档），把仓库整理成一眼能看懂的样子。

## 目录结构

```
somecode/
├── tools/                    # 小工具（成品 / 在研）
│   ├── 基金查询工具/          # 已完成：零依赖基金数据查询
│   └── 快递驿站管理系统/      # 进行中：命令行完成，Web 端实验性未完成
├── archive/                  # 学习归档（留作记录，不再主动维护）
│   ├── learning/             # 廖雪峰 Python 教程跟练、PySide6 练习
│   └── 学习记录/             # 学习日志
├── README.md
└── .gitignore
```
